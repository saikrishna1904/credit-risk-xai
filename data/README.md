# Data

The data files are not in this repo because they are 1–2 GB each.

1. Download the LendingClub loan data (2007–2018Q4) from Kaggle:
   https://www.kaggle.com/datasets/wordsforthewise/lending-club
2. Put these two files in this folder:
   - `accepted_2007_to_2018Q4.csv`
   - `rejected_2007_to_2018Q4.csv`
3. Run `notebooks/01_data_preparation.ipynb`. It creates `accepted_cleaned.csv` here.
